# DS_Tuc_Ab-HST-analysis-notebooks
HST Data analysis notebooks to reproduce the results for the exoplanet DS Tuc Ab from Dos Santos et al.

To use these notebooks and reproduce our results, you will need to download the data publicly available on Zenodo: https://zenodo.org/records/22778164.

You will also need to install the following Python packages:
- NumPy
- SciPy
- Matplotlib
- Astropy
- astroquery
- astroplan
- [sunburn](https://github.com/ladsantos/sunburn)
- [emcee](https://emcee.readthedocs.io)
- [costools](https://github.com/spacetelescope/costools)
- [stistools](https://github.com/spacetelescope/stistools)
- [calcos](https://github.com/spacetelescope/calcos)
- [onza](https://github.com/ladsantos/onza)
